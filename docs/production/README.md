# AegisAI 실배포 문서

2026년 11월 8일 기준, 기존 AWS EC2 한 대에서 Tailscale을 통한 비공개 Java 보안 분석 서비스를 운영한다. 실제 GitHub 조직 저장소를 가져와 Opengrep·Trivy·Syft로 분석하고, 결과와 암호화된 근거 자료를 저장하는 경로가 동작한다. AI는 꺼져 있으며 로그인·스캔·결과 조회에 모델이나 API 키가 필요하지 않다.

이 문서는 현재 구현과 확인된 결과를 설명한다. 전체 제품 명세의 다중 테넌트 서비스, 별도 노드 격리, 고가용성까지 완료했다는 의미는 아니다. 기준 명세와의 차이는 [남은 작업과 적용 범위](./remaining-work.md)에 기록한다.

## 사용 가능한 기능

- 허용된 GitHub 계정으로 실제 로그인하고, 별도 GitHub App으로 연결된 조직 저장소를 확인한다.
- 저장소와 브랜치를 선택해 분석을 요청한다. 서버가 GitHub에서 확인한 커밋을 고정하며 클라이언트가 커밋이나 정책을 임의로 지정할 수 없다.
- 분석 상태, 도구별 실행 결과, 제한된 분석 범위, 정규화된 발견 항목을 조회한다.
- 권한과 만료 시각을 확인한 뒤 분석 근거를 내려받는다. 근거 조회는 감사 기록을 남긴다.
- AI가 없어도 위 경로를 사용할 수 있다. 향후 자체 로컬 모델이 목표이며 외부 API는 임시 대안으로 허용돼 있다.

사용 주소는 [AegisAI 비공개 서비스](https://aegisai-aws.tailaca7d2.ts.net/)다. Tailscale 연결과 허용된 계정이 필요하다. 공개 가입, 공개 웹훅, 외부 공개 접속은 제공하지 않는다.

## 실제 사용 기술

| 영역 | 현재 적용 | 역할 |
| --- | --- | --- |
| 호스트 | AWS EC2, Ubuntu 24.04, 암호화 EBS | 단일 서비스 호스트와 영속 디스크 |

정확한 이미지·DB 해시와 배포 출처는 검증 기록을 따른다. 버전이 적혀 있다는 이유만으로 최신 버전 유지나 취약점 부재를 보장하지 않는다.

## 현재 운영 수준

실제 저장소 스캔, 소스 정리, 암호화 근거 접근, 백업 복원, 서버 재시작 복구 및 비공개 접근 차단·복원은 확인했다. 사용자는 휴대폰에서 실제 저장소 목록과 완료된 스캔을 확인했다.

실제 동시 분석은 한 건이다. 화면·API·DB·스캐너가 같은 EC2에 있으므로 호스트 장애가 전체 서비스에 영향을 준다. 외부 알림, 정량 SLO, 부하 벤치마크, AWS 자동 배포, 깨끗한 커밋 기반 릴리스는 아직 완료하지 않았다. 이전의 미암호화 복구 사본과 비활성 로컬 비밀 사본도 예외로 남아 있다.

2026년 11월 9일 별도 소스 후보를 커밋하고 hosted CI를 통과시켰다. 운영 코드는 여전히 이전 배포 아카이브에서 실행되며, 현재 dev와의 통합과 해당 커밋 기반 재배포는 하지 않았다. 자세한 출처는 위 Git 연결 문서를 따른다.

## 비용 범위

EC2 외에도 S3 저장·요청, Secrets Manager와 KMS 요청, 보존 중인 EBS·스냅샷 비용이 발생한다. 추가 컴퓨팅을 만들지 않았다는 사실이 추가 요금이 없다는 뜻은 아니다. 월별 금액 상한을 강제하는 장치나 AWS Budgets 알림은 현재 적용을 확인하지 못했다. 큐·소스·메모리·디스크 제한은 자원 상한이며 청구 금액 상한과 다르다.

## 문서 유지 기준

설계 의도는 007 명세, 현재 운영 사실은 이 문서 묶음, 과거 단계는 날짜가 붙은 체크포인트로 구분한다. 코드나 배포가 바뀌면 배포 기록과 운영 절차를 함께 갱신한다. 문서에 비밀번호, 개인 키, OAuth 비밀 값, AWS 로그인 코드, 저장소 원문을 넣지 않는다. 과거 로그의 성공을 새 릴리스의 성공으로 대신 기록하지 않는다.

007 통합 후보는 배포 전 준비 단계다. 기존 운영 증거는 새 후보의 배포 성공을 뜻하지 않는다. 비활성 로컬 비밀 사본 3건은 2026-11-09 관리형 비밀 확인 후 제거했으며, 이전 디스크·스냅샷은 유지했다.
