# Expo3 typography

Matches the main website's Newsreader wordmark and Inter body typography. Fonts are served from the application origin so the exhibition page does not depend on Google Fonts at runtime or require broader CSP permissions. Korean text uses the local sans-serif/serif fallback stacks.

- `newsreader-brand.woff2`: Newsreader 700, Google Fonts subset for `AegisAI0123`, downloaded 2026-09-28. License: `Newsreader-OFL.txt`.
- `inter-latin.woff2`: Inter variable 400–800, Google Fonts Latin subset, downloaded 2026-09-28. License: `Inter-OFL.txt`.
